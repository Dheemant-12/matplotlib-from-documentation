# Matplotlib From Official Documentation

## About

This repository documents my journey of learning Matplotlib directly from the official documentation.

Instead of following random tutorials, every concept is learned, implemented, and documented using examples inspired by the official documentation.

---

## Goals

- Learn Matplotlib from the official documentation
- Build reusable plotting examples
- Understand both pyplot and Object-Oriented interfaces
- Create a reference repository for future projects
- Maintain a daily learning log
